# Учебный проект по проектированию REST API

## Бизнес-задача

Нужен сервис для хранения текстовых заметок. Пользователь может:

- посмотреть список заметок;
- открыть одну заметку по идентификатору;
- создать новую заметку;
- удалить ненужную заметку;
- изменить статус заметки.

## Бизнес-правила

1. `id` и `created_at` присваивает сервер, клиент их не передаёт.
2. Новая заметка всегда создаётся со статусом `draft`.
3. Заголовок обязателен, его длина от 1 до 100 символов.
4. Статус можно менять между любыми допустимыми значениями, ограничений на порядок переходов нет.
5. Удаление безвозвратное, повторный вызов возвращает `404`.

## Эндпоинты

| Метод | Путь | Назначение | Коды ответов |
|---|---|---|---|
| GET | `/notes` | Список заметок | 200 |
| POST | `/notes` | Создать заметку | 201, 400 |
| GET | `/notes/{noteId}` | Получить заметку | 200, 404 |
| DELETE | `/notes/{noteId}` | Удалить заметку | 204, 404 |
| PATCH | `/notes/{noteId}/status` | Изменить статус | 200, 400, 404 |

## Как посмотреть документацию

1. Откройте [editor.swagger.io](https://editor.swagger.io).
2. Вставьте содержимое файла `openapi.yaml`.
3. Справа отобразится документация, а на каждом методе можно нажать «Try it out».

Для проверки через Postman: Import → выбрать `openapi.yaml`, коллекция запросов соберётся автоматически.
